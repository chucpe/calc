[Калькулятор](https://github.com/chucpe/calc/raw/refs/heads/master/src/calc.user.js) заявок для e8.ffa.su
Пользовательский скрипт (UserScript) для автоматизации расчёта заработка, подсчёта паллет и контроля рабочего времени на платформе e8.ffa.su. Скрипт внедряется в интерфейс сайта в виде удобной плавающей панели и не требует установки дополнительного ПО.

🚀 Основные возможности

💰 Калькулятор и статистика

- Автоматический расчёт суммы за смену.

- Гибкая формула расчёта: Сумма = отверстия × ставка × (1 − НДФЛ) × паллеты. Все параметры (ставка, НДФЛ) настраиваются.

- Специальные ставки

- Подсчёт количества изделий (из поля quantity) за выбранный период.

- Статистика по продуктам: Топ-10 позиций по количеству отверстий, общий заработок, потраченное время и количество паллет.

- Экспорт в CSV: выгрузка детального отчёта, где каждая паллета — отдельная строка.


🗓️ Календарь смен и праздников

- Визуальный график смен: 3 бригады (Голубая, Фиолетовая, Оранжевая), цикл 4/2 (4 дня работы, 2 выходных).

- Разделение дня и ночи: верхняя половина ячейки — дневная смена (☀️), нижняя — ночная (🌙).

- Фильтр по сменам: клик по кнопке «Смена 1/2/3» подсвечивает только её дни, остальные приглушаются.

- Производственный календарь РФ: официальные праздники и перенесённые выходные (2025–2027 гг.) отмечаются желтой точкой.


👥 Модуль «Онлайн» (Сотрудники)

- Мониторинг статусов: показывает, кто сейчас в сети, а кто офлайн (с временем последнего визита в МСК).
- Синхронизация с GitHub: список сотрудников (ФИО, рабочее место, комментарии).

⚙️ Дополнительно

- Фильтр по датам: расчёт суммы и паллет только за выбранный период.

- Фильтр по заявкам: возможность считать только конкретные номера (например, 30-40 или 30,32,35).

- Информер localStorage: показывает, сколько места занимают данные скрипта.

- Автосворачивание: панель может автоматически скрываться в «кружок» после загрузки.

- Кнопка «Пересчитать»: делает реальный запрос к API для получения свежих данных без перезагрузки страницы.

- Cкрытие лишнего: убирает баннеры «Установка приложения» и «Напоминание», блокирует всплывающее окно «Характеристики продукции».
